# Program Workout 12 Minggu

Program latihan di rumah dengan satu dumbbell 5 kg. Latihan dibagi menjadi hari
upper body dan lower body agar otot sejenis dilatih bersama. Setiap sesi utama
hanya berisi 4 gerakan dengan durasi sekitar 20–30 menit.

## Peralatan

- 1 dumbbell 5 kg
- Kursi atau pijakan yang kokoh
- Ruang lantai atau matras

## Tujuan Program Ini

- Meningkatkan massa otot (*hypertrophy*) dengan progressive overload.
- Meningkatkan kekuatan dan daya tahan otot.
- Membentuk six-pack dan core yang kuat.
- Membuat lengan, khususnya biceps dan triceps, lebih berisi.
- Membentuk bahu yang lebih lebar dan menjaga postur optimal.
- Menjaga kesehatan kardiovaskular dengan lari mingguan.
- Menjaga fleksibilitas dan mendukung pemulihan.

## Jadwal Mingguan

| Hari | Aktivitas | Durasi |
| --- | --- | --- |
| Senin | Upper Body A — dada, punggung, bahu, dan biceps | 20–30 menit |
| Selasa | Lower Body A — kaki, posterior chain, dan core | 20–30 menit |
| Rabu | Istirahat total | — |
| Kamis | Upper Body B — dada, punggung, triceps, dan biceps | 20–30 menit |
| Jumat | Fleksibilitas dan pemulihan aktif | 15–25 menit |
| Sabtu | Lower Body B — kaki, betis, dan core | 20–30 menit |
| Minggu | Lari easy pace | 25–40 menit |

## Panduan Singkat

- Lakukan pemanasan 4–5 menit sebelum sesi utama.
- Istirahat 45–75 detik antarset.
- Pada gerakan satu tangan atau satu kaki, selesaikan sisi kanan dan kiri.
- Hentikan set ketika masih mampu melakukan sekitar 2 repetisi tambahan dengan
  teknik yang baik.
- Set yang tertulis merupakan target minggu 3–11. Penyesuaian minggu 1–2 dan 12
  dijelaskan pada bagian progresi.
- Tautan pada nama gerakan membuka panduan gerakan di Fitbod.

## Pemanasan Setiap Sesi

1. March in Place — 1 set x 60 detik.
2. Bodyweight Squat — 1 set x 10 repetisi.
3. Hip Hinge tanpa beban — 1 set x 10 repetisi.
4. Arm Circle — 1 set x 10 putaran ke depan + 10 putaran ke belakang.

## Rotasi Latihan Biceps

Senin menggunakan **Biceps Slot A**, sedangkan Kamis menggunakan **Biceps Slot
B**. Rotasi empat minggu ini memastikan semua variasi tetap digunakan tanpa
menumpuk terlalu banyak gerakan dalam satu sesi.

| Minggu | Biceps Slot A — Senin | Biceps Slot B — Kamis |
| --- | --- | --- |
| 1, 5, 9 | [Dumbbell Bicep Curl](https://fitbod.me/exercises/dumbbell-bicep-curl) — 2 set x 10–20 repetisi/lengan | [Hammer Curls](https://fitbod.me/exercises/hammer-curls) — 2 set x 10–20 repetisi/lengan |
| 2, 6, 10 | [Cross Body Hammer Curls](https://fitbod.me/exercises/cross-body-hammer-curls) — 2 set x 10–18 repetisi/lengan | [Concentration Curl](https://fitbod.me/exercises/concentration-curl) — 2 set x 10–18 repetisi/lengan |
| 3, 7, 11 | [Waiter Curls](https://fitbod.me/exercises/waiter-curls) — 2 set x 12–20 repetisi | [Biceps Curl to Shoulder Press](https://fitbod.me/exercises/biceps-curl-to-shoulder-press) — 2 set x 8–15 repetisi/lengan |
| 4, 8, 12 | [Dumbbell Hammer Pause Curl](https://fitbod.me/exercises/dumbbell-hammer-pause-curl) — 2 set x 8–15 repetisi/lengan | [Dumbbell Bicep Curl](https://fitbod.me/exercises/dumbbell-bicep-curl) — 2 set x 10–20 repetisi/lengan |

Pada minggu 12, lakukan setiap Biceps Slot hanya 1 set sebagai bagian dari
deload.

## Senin — Upper Body A

Fokus: dada, punggung atas, bahu, dan biceps.

1. [Push Up](https://fitbod.me/exercises/push-up) — 3 set x 8–15 repetisi.
2. [Prone T's](https://fitbod.me/exercises/prone-t-s) — 3 set x 10–15
   repetisi. Tahan 1–2 detik di posisi atas.
3. [Standing Single Arm Dumbbell Shoulder Press](https://fitbod.me/exercises/standing-single-arm-dumbbell-shoulder-press) —
   3 set x 10–15 repetisi/lengan.
4. **Biceps Slot A** — 2 set sesuai rotasi minggu.

Jangan mengayun badan saat shoulder press atau curl. Kencangkan core dan jaga
punggung tetap netral.

## Selasa — Lower Body A

Fokus: paha, hamstring, glutes, dan core.

1. [Dumbbell Goblet Squat](https://fitbod.me/exercises/dumbbell-goblet-squat) —
   3 set x 10–20 repetisi.
2. [Dumbbell Good Morning](https://fitbod.me/exercises/dumbbell-good-morning) —
   3 set x 12–20 repetisi.
3. [Dumbbell Glute Bridge](https://fitbod.me/exercises/dumbbell-glute-bridge) —
   3 set x 12–20 repetisi. Tahan 1–2 detik di posisi atas.
4. [Dead Bug](https://fitbod.me/exercises/dead-bug) — 3 set x 8–12
   repetisi/sisi.

Pada Dumbbell Good Morning, pegang dumbbell di depan dada, tekuk lutut sedikit,
dorong pinggul ke belakang, dan pertahankan punggung netral.

## Kamis — Upper Body B

Fokus: dada, punggung atas, triceps, dan biceps.

1. [Single Arm Floor Press](https://fitbod.me/exercises/single-arm-floor-press) —
   3 set x 10–18 repetisi/lengan.
2. Minggu ganjil: [Prone W's](https://fitbod.me/exercises/prone-w-s). Minggu
   genap: [Prone Y's](https://fitbod.me/exercises/prone-y-s) — 3 set x 10–15
   repetisi. Tahan 1–2 detik di posisi atas.
3. [Seated Tricep Press](https://fitbod.me/exercises/seated-tricep-press) — 3
   set x 10–18 repetisi. Pegang satu dumbbell dengan kedua tangan.
4. **Biceps Slot B** — 2 set sesuai rotasi minggu.

Jaga siku tetap mengarah ke depan saat Seated Tricep Press. Hentikan gerakan
jika bahu atau siku terasa nyeri.

## Sabtu — Lower Body B

Fokus: paha, glutes, betis, dan core.

1. [Reverse Lunge](https://fitbod.me/exercises/reverse-lunge) — 3 set x 8–15
   repetisi/kaki.
2. [Step Up](https://fitbod.me/exercises/step-up) — 3 set x 10–15
   repetisi/kaki. Gunakan hanya kursi atau pijakan yang tidak licin dan tidak
   goyah; ganti dengan Goblet Squat bila pijakan tidak aman.
3. [Single Leg Standing Calf Raise](https://fitbod.me/exercises/single-leg-standing-calf-raise) —
   3 set x 12–25 repetisi/kaki. Pegang kursi untuk menjaga keseimbangan.
4. Minggu ganjil: [Plank](https://fitbod.me/exercises/plank) — 3 set x 30–60
   detik. Minggu genap: [Leg Raise](https://fitbod.me/exercises/leg-raise) — 3
   set x 10–15 repetisi.

## Progresi 12 Minggu

| Fase | Set dan intensitas |
| --- | --- |
| Minggu 1–2 | Lakukan 2 set untuk setiap gerakan. Gunakan teknik terkontrol dan sisakan sekitar 3 repetisi. |
| Minggu 3–4 | Ikuti jumlah set dan repetisi yang tertulis. Sisakan sekitar 2–3 repetisi. |
| Minggu 5–8 | Naikkan repetisi sampai batas atas, lalu gunakan tempo turun 3 detik atau jeda 1 detik. |
| Minggu 9–11 | Pertahankan jumlah set. Sisakan sekitar 1–2 repetisi pada set terakhir tanpa merusak teknik. |
| Minggu 12 | Deload: lakukan 2 set per gerakan, Biceps Slot 1 set, dan sekitar 60–70% repetisi normal. |

### Urutan menambah tantangan dengan dumbbell 5 kg

1. Tambahkan 1–2 repetisi per set hingga mencapai batas atas.
2. Perlambat fase turun menjadi 3 detik.
3. Tambahkan jeda 1–2 detik pada posisi tersulit.
4. Perbesar rentang gerak selama teknik tetap aman.
5. Gunakan pola 1,5 repetisi.

Jika batas repetisi tertinggi masih terasa ringan setelah memakai tempo dan
jeda, dumbbell 5 kg mungkin sudah membatasi progres. Beban yang dapat
disesuaikan atau resistance band dapat menjadi peningkatan alat berikutnya.

Variasi Prone T/W/Y membantu melatih kontrol tulang belikat dan postur. Jika
suatu saat tersedia resistance band atau pull-up bar, tambahkan gerakan menarik
agar latihan punggung dapat berkembang lebih jauh.

## Jumat — Fleksibilitas dan Pemulihan Aktif

1. Jalan santai — 10–15 menit.
2. Hip Flexor Stretch — 2 set x 30–45 detik/sisi.
3. Hamstring Stretch — 2 set x 30–45 detik/sisi.
4. Child's Pose — 2 set x 30–60 detik.

Peregangan cukup terasa ringan sampai sedang dan tidak perlu dipaksa hingga
nyeri. Rabu tetap menjadi hari istirahat total.

## Minggu — Lari Mingguan

- Minggu 1–2 — easy run atau kombinasi lari-jalan selama 25 menit.
- Minggu 3–4 — easy run selama 30 menit.
- Minggu 5–8 — easy run selama 30–40 menit.
- Minggu 9–11 — easy run 5 km atau maksimal 40 menit.
- Minggu 12 — recovery run atau lari-jalan selama 20–30 menit.

Gunakan pace yang membuat napas lebih cepat tetapi masih memungkinkan berbicara
dalam kalimat pendek. Tidak perlu sprint atau mengejar pace. Bila kaki masih
sangat lelah dari latihan Sabtu, pilih kombinasi lari-jalan.
